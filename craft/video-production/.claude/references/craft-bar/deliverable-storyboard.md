# Deliverable rubric — storyboard (the card/beat plan)

The storyboard's own grading criteria — one card per beat, in playback order. Builds on `a1-frame.md` (frame craft, signature, hero number) and `a4-pacing.md`, plus the production's `b-*.md` profile (arc + close + length).

- **Arc.** First card is a hook, NOT a logo/title (§A4); last card is the close the §B profile owes (a launch's explicit on-screen CTA, a teaser's deferred tease…). Beats in sensible order; count matches the §B length band (~4–6 for a ~15s short).
- **Coverage.** Uses the approved script's VO lines **verbatim, in order, each once**. The CTA line appears only on the final card. Every required message is covered. Name a dropped or reordered line.
- **Signature & hero (`a1-frame.md`).** Names ONE signature move and assigns it to specific card(s). If a hero number/receipt exists, it owns its own full-frame beat — not a footnote.
- **Framing (`a1-frame.md`).** Each beat has a DISTINCT focal subject that dominates the safe area — no two near-identical cards (slideshow), no wall of text. Colour-per-beat variety and the moodboard's sourced font carried through. A frozen sparse end card is the worst offender.

Each card's brief is self-contained: the beat's subject, the VO line(s) it carries, the visual direction, and which signature/hero move (if any) it holds.
