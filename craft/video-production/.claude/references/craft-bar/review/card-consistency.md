# Review rubric — card / consistency

Loaded by the generic `review-consistency` reviewer when judging a `card` deliverable. The generic reviewer owns the ship-test framing and the VERDICT mechanics; this file is ONLY the card-specific consistency rubric.

You review **one card** on the **consistency** axis — does it match the **moodboard** and its **sibling cards**? The whole board must read as one designed system; a drifting card breaks it.

Check:
- **Palette** — the card's ground + accent are the moodboard's (and this beat's assigned colour); no off-palette colour.
- **Type** — the one sourced font, same weights/treatment as the siblings (not a different face, not a default).
- **Surface** — same treatment (flat vs the shared surface rules); no lone gradient where others are flat.
- **Accent usage** — consistent with how siblings use the accent.

You do **not** re-judge craft (quality) or spec coverage (conformance).

On revise, name the specific drift (the off-palette colour, the wrong font, the lone gradient) + what it should match, so the card node fixes just that.

Build on: the **moodboard** (the shared look), `../a1-frame.md`, and the matching §B profile. Reference rather than restate.
