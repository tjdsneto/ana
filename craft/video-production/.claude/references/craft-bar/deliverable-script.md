# Deliverable rubric — script (the spoken VO)

The script's own grading criteria. Builds on `a2-proof.md` (grounding), `a3-slop.md`, `a4-pacing.md`, and the production's `b-*.md` profile (the close the type owes). Judge a script on these; a producer aims at them.

- **Hook (line 1).** The first line is a benefit/outcome or a desire question — never the brand/product name, never a logo/title-card equivalent in words (§A4). The product name may be withheld a few seconds. A cold open on the brand name is the measurably weakest option.
- **Density (the ceiling, not a target).** ≤ ~2.5 words/sec; airy (~1.7 wps) is correct for a cinematic register. Roughly 3–5 speakable lines / ~12–18s for a short. **These counts are reviewer signals, not hard gates** (issue 0018): never compress a script past the point of cutting a required message to hit a word count — a missing product reveal is a worse failure than a few words over.
- **Close.** The final line matches the §B profile's close: a launch owes an explicit CTA ask (a concrete labelled action), a demo a next-step, a teaser a deferred tease, an explainer a learn-more. A soft tagline where the type wants a hard ask is a miss.
- **Brief coverage.** Every required message the brief names actually lands in the VO. Name the one that is missing.
- **Grounding (guardrail — can't be fixed in review).** Claims only facts the brief states; invents nothing; none of the forbidden claims (rankings, reviews, ads) appear. This is a produce-time guardrail — prevent, don't reject-and-redo.

One idea per line — if a line says two things, it is two lines (§A4).
