# issues/

A lightweight, in-repo issue log. We don't have a hosted repo / tracker yet, so findings that deserve a ticket live here as markdown files until there is somewhere to file them properly.

## Convention

- One file per issue: `NNNN-short-kebab-title.md` (zero-padded, incrementing).
- Keep the body plain: **Summary**, **Severity**, **Repro**, **Root cause**, **Impact**, **Suggested fix**, **Status**.
- Set `Status: open` / `in-progress` / `closed` in the body; note the fixing commit when closed.
- When a real tracker exists, migrate these and leave a pointer.
